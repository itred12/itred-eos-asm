## **Space:**

- The patch requires ExtraSpace to be applied, and takes up 42 bytes of space in overlay 36, starting from `0x33F70` (from the start of ov36) and ending at `0x33FAA`. 

    - If you aren't sure what this means, then that's okay– know that it won't conflict with any applied patch given by Skytemple; however, if you're using other community-made patches that also utilize ExtraSpace, then patch overlap could occur. <u>Please be aware of the position and size of the community-made patches you're using.</u>
